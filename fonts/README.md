# 한글 폰트 설치 안내

PDF 한글 출력을 위해 다음 파일을 이 폴더에 배치해주세요:

1. NotoSansKR-Regular.ttf
2. NotoSansKR-Bold.ttf

다운로드: https://fonts.google.com/noto/specimen/Noto+Sans+KR
- "Download family" 클릭
- 압축 해제 후 위 파일을 이 fonts/ 폴더에 복사

또는 아래 명령어로 다운로드:
```
curl -o NotoSansKR-Regular.ttf "https://github.com/google/fonts/raw/main/ofl/notosanskr/NotoSansKR-Regular.ttf"
curl -o NotoSansKR-Bold.ttf "https://github.com/google/fonts/raw/main/ofl/notosanskr/NotoSansKR-Bold.ttf"
```
